## 示例场景：SSH 连接失败

```
1. 用户请求：检查 192.168.1.100 的 CPU
   └─> Agent 调用 check_cpu(host="192.168.1.100")

2. 工具执行：SSH 连接
   └─> 失败：dial tcp 192.168.1.100:22: connection refused

3. 错误检测：ErrorRecoveryEngine.RecoverFromError()
   ├─> findStrategy("check_cpu", "connection refused")
   ├─> 匹配策略 #1：SSH connection refused
   └─> 策略配置：
       ├─ CanRetry: true
       ├─ AlternativeTools: ["run_command"]
       └─ RecoveryCommands: ["ping -c 3 {host}"]

4. 恢复流程：
   ├─> 生成恢复提示
   ├─> 执行自动命令：ping -c 3 192.168.1.100
   └─> 构建替代工具：
       └─> run_command(host="192.168.1.100", command="top -bn1 | head -20")

5. 执行替代工具：run_command
   └─> 成功：返回 CPU 使用率信息

6. 返回结果：
   └─> "原工具失败，使用替代方案 run_command 成功"
```
