# AI-Ops 开发任务清单

## 项目概述

基于 Go + 本地 LLM 的轻量级 AI Agent 运维平台，通过自然语言对话完成日常运维操作。

## 技术栈

| 组件 | 技术选型 |
|------|----------|
| 后端 | Go + Gin + GORM |
| 数据库 | SQLite (可切换 PostgreSQL) |
| LLM | OpenAI 兼容接口 (Ollama) |
| SSH | golang.org/x/crypto/ssh |
| 前端 | Vue3 + TypeScript + Element Plus + Pinia |
| 构建 | Vite |

### 6.3 Agent Loop 实现

**目标**: 实现核心 Agent 循环

**任务**:
- [ ] 创建 `internal/agent/agent.go`
- [ ] 定义 Agent 结构体 (llm, tools, ssh, maxLoops)
- [ ] 实现 Chat 方法
- [ ] 实现循环: 调用 LLM → 解析输出 → 执行工具 → 继续或返回
- [ ] 实现最大循环次数限制
- [ ] 实现错误处理和恢复

**核心流程**:
```
1. 添加用户消息到历史
2. 构造 Prompt
3. 循环:
   a. 调用 LLM
   b. 解析输出
   c. 如果是工具调用 → 执行工具 → 添加结果到历史 → 继续
   d. 如果是最终回复 → 返回
4. 达到最大循环 → 报错
```

## 注意事项

1. **安全性**: SSH 凭证加密存储，危险命令拦截，审计日志
2. **错误处理**: 所有外部调用需要超时和错误处理
3. **并发控制**: SSH 连接池、批量执行并发限制
4. **可扩展性**: Tool 系统支持动态扩展
5. **用户体验**: 流式输出、加载状态、错误提示
